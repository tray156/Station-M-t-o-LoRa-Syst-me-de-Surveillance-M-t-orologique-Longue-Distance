📊 Données Transmises

📤 Émission (Tunis)

  • Température : °C (précision 0.1)
  • Humidité : % (précision 1)
  • ID Station : "TUNIS"
  • Compteur : Numéro paquet

📡 Envoi toutes les 30 secondes
💾 Format: CSV (léger)
🔐 CRC activé (fiabilité)

📥 Réception (La Marsa)

  • Affichage OLED : Temp & Humidité
  • RSSI : Force du signal
  • Compteur : Paquets reçus
  • Taux réussite : % de succès

🔴 LED rouge = Réception
🟢 LED verte = Connexion OK
📺 Dashboard web temps réel

🚀 Pourquoi LoRa ?

Avantages Techniques

  • Portée: 10-15 km (urbain), 30+ km (rural)
  • Pénétration: Traverse les obstacles
  • Consommation: Ultra-faible (années sur batterie)
  • Coût: Aucun abonnement requis
  • Fiabilité: Résistant aux interférences

Configuration Optimale

Spreading Factor: SF12 (max portée)

Bandwidth: 125 kHz

Coding Rate: 4/5

TX Power: 20 dBm (max)

Fréquence: 868 MHz (EU)

Portée optimisée pour 18 km
